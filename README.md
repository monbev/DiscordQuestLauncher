# DiscordQuestLauncher

Accept quests, run them with one click, and get notified when new ones arrive. A BetterDiscord plugin with an English interface.

## Install

1. Download the plugin using the button above.
2. In Discord, go to **Settings → BetterDiscord → Plugins → Open Plugins Folder**.
3. Drop the downloaded `.plugin.js` file into the folder and enable it.

Requires BetterDiscord and the official Discord desktop client. No extra libraries needed.

## Use

Open **Quests**, choose your filters, then click **Accept new** to accept matching visible quests. Click **Play** to run all accepted quests, or **Pause** to stop. Claim rewards in Discord when they're ready.

- **Filters:** All / New / In progress / Rewards.
- **Parallel execution:** one video and one game/activity quest at a time.
- **Progress:** quest names, live bars and approximate time remaining.
- **Notifications:** sound, snooze, and a click to open Quests — including Windows notifications.

Notification timing and sound can be adjusted in the plugin settings. New quests are checked every **3 minutes** by default.

## Good to know

- Accept new follows your filters; Play runs **all accepted quests**.
- Platform selection and other manual dialogs still need your input. Stream quests need you to share a window with someone in the voice channel.
- Don't run another quest automation plugin or script at the same time.
- If claiming a reward fails, try your browser or phone.
- Discord updates can break compatibility. This is an unofficial plugin.

Updates appear inside BetterDiscord with an **Update** button. If you're on 1.0.0, download the latest file once to get the updater.
